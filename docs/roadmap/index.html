done 0 now 3 next 6 later 0
  • now
    Portable storage core

    one database and settings per person, simpler safety checks on Mac, backup and same-person restore, with no folder relocation.

  • next
    Sign-up and accounts

    require Touch ID and a Duo security key, both added in Duo's device management at duo.ucpath.edu. Use a Chromium virtual platform authenticator where the machine has no Touch ID hardware. Logout keeps credentials. Put Delete account in Settings > General. An empty machine says to sign up first. Back up the old store, then start clean.

  • now
    Workflow logins

    use fast-duo for every workflow login and remove duo-autopilot before the dry runs.

  • next
    Runs

    add Pause and Resume, "Pause all and quit" and reruns of failed items only. A crash parks items caught mid-submit as unknown.

  • next
    Write safety

    take screenshots at every browser step and before and after submit. Dry runs fill the whole workflow with sample values where needed, without submitting. UCPath shows transaction-list findings for the operator to decide. Kuali keeps its reload check.

  • next
    OCR and Emergency Contact on the new core

    review OCR, save corrections as revisions and feed approved snapshots into Emergency Contact.

  • now
    Dashboard cleanups

    make Explorer read-only, have the assistant always ask before acting and propose workflow starts, save appearance preferences per person and put Backup/Restore in Settings.

  • next
    Operator preview

    complete the full test pass and verify a backup before preview.

  • next
    Workflow sign-off

    Person Lookup live read and sign-off, then Separations dry run and sign-off, then OCR to Emergency Contact dry run and sign-off, then real runs.
