   `urls.<system>.prod` route sets, `actor.id` and the Duo WebAuthn credential file (§D331.2).
   The launch nonce and `test-only` keys are excluded from the catalog by name.

   secret that is not a provider key has exactly one place under D327's letter; the pair is one row

   label by `docs/migrations/person-lookup.md` under D318's `live-read` arm; D300's "only" is read as
   "only of separations" — dated note on the D300 row, §D331.12 item 6. Not escalated.
4. **`timekeeperName` leaves `ConfigSchema`** (`operator.timekeeperName` deleted); historical
   `config_snapshots`/backups retain it as named accepted exposure (§D331.6 rule 8); 1.6 owes a
   `snapshot-generations` retirement arm (P38).
5. **Protected revision is NOT a claim-token field; the settings fingerprint covers the ordinary
   document only** — rejecting the analyst's per-leaf salted digest (§D331.7): a rotation must not
   make idle workers stale and a digest of a password in a non-0600 table is an oracle.
6. **Journal = marked envelope (`"<set>"`) + random `writeId`; replay divergence = constant-time
   comparison under the lock; no MAC, no digest anywhere** (§D331.5/§D331.6 rule 4 — the in-file
   MAC of the first draft was removed on adversarial finding 8b).
7. **Model chains are ordinary settings** (`providers.<family>.models`); `providerModelChain` loses
   both env reads; the singular `OCR_*_MODEL` spellings retire with them (§D331.2, §D331.8).
8. **`migrated-refused` is a NEW registry disposition**; `retired-in-target` keeps its inert meaning
   (§D331.8) — so an exported `DEBUG=1` cannot refuse boot.
9. **Arm 1 patch entries are `{ set } | { clear }`** — the as-built merge cannot unset a leaf (§D331.5).
10. **Backups copy `settings.json` + `authority.json`, never `protected.json`**; `rootFingerprint`
    covers the sidecar tuple only (§D331.3).
