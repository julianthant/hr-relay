## Design decisions made in this run (all inside D327's scope)

1. **Three-way existence** (`absent` / `present{live|archived}` / `deleted`) with a one-way disposition
   axis; `authority-unknown` mapped to `absent` + doctor finding (Task 3 decides re-admission).
2. **Seven-state machine and outcome union adopted verbatim** from workflow-model §4 / `record.ts`;
   the tree rule is now normative in §D330.3 (no other doc stated it): anchor cannot settle while a
   member is non-terminal, cancel-tree fans out first, member `interrupted` requeue refuses under a
   terminal anchor, `is-member` = `parent` present (never `sessionId`).
3. **One `version` CAS token** (wire `rowRevision` is that value served; pool version is a different
   row) + **`claimGeneration` fence** (refuses when differing OR absent); settle needs fence + version +
   state; a settings/runtime generation advance never touches an in-flight claim.
4. **Closed operation set with named refusals** and a **wire mapping** onto `CommandRejectionCode`;
   1.6 widens the union by exactly one code, `target-deleted`, so `deleted` never collapses into
   `absent` on the wire. As-built throws become refusal arms in 1.6.
5. **Total queue order** priority → enqueuedAt → runId; claim = one SQLite write transaction including
   the runtime-generation proof; the runtime token is required in full (no absent-skip arm).
6. **Retry/restart/relaunch** as three lineages; relaunch never carries `retryOf`.
7. **"Purge" = retention of evidence only**; the never-built `cli purge-run` row (§2.4) and the §2.3
   "Purge procedure" sentence are superseded to D308 delete.
8. **Spent ordinals survive delete:** tombstone gains `itemId`/`attempt`/`runNumber`; watermarks read
   `tasks` ∪ `deleted_runs` (highest-severity adversarial finding).
9. **Anchor delete cascades members**, one tombstone per run, restoring D308's dropped clause.
10. **`checkpoint_payloads` holds only run-owned gate records** — they leave with the run; D308's
    "stays" list corrected by dated note; 1.6 adds the relaxed trigger + tally column.
11. **`archive_relaunches` is owned by the NEW run**; deleting the source keeps the lineage row.
12. **D268 superseded in part** (fold `ended`/`claimedBy` are no longer lifecycle inputs; code change is
    2.6's) and **`runs_view` retired as a state read** — both are applications of D327's letter, marked
    with dated notes. Coordinator verification requested (see "Decisions to verify").
