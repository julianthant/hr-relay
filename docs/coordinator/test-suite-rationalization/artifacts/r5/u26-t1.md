## Synthetic authority boundary

- Person lookup uses fixture EIDs `10800000`/`10800001` and fixture names.
- Identity, Kronos, Kuali-read, UCPath termination, finalization, and composition cases use fixture
  identities/documents/transactions while preserving the historical response shape or failure arm.
- A structural test may prove a real task, driver interpreter, graph, write sequencer, SQLite delta,
  refusal, idempotency, or redaction behavior. It does not prove that an external system or current
  employee has that state.
- T1b remains the only live-observation declaration, and neither T1b file is collected by Vitest.
