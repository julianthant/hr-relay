## Census and method

At implementation head `4d5ecd713d47e9ecebee21712e761f4ef813ee7a`, the `scenario` Vitest project
collects **17 files / 142 cases**: six capability files / 33 cases, seven workflow T1a files / 81
cases, three R5b-owned dashboard T2 files / 26 cases, and one R5b-owned integration walk / 2 cases.

Vitest cases. `rg '^\s*it\("' tests/scenario --glob '*.test.ts'` and the verbose scenario-project
gate supplied the case census; `scenario-coverage` supplied the independent manifest/corpus check.

Case lists below are complete. For slash-prefixed cases, the text before the em dash is the exact
registered case head; non-registered support assertions retain their complete title. Evidence codes:
`G` graph walk/derived point, `T` task or contract behavior over synthetic/local fixtures, `S`
write-sequencer/SQLite authority, `D` dashboard projection/command behavior, `W` integration walk,
and `U` uncollected live-observation declaration.
