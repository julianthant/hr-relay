## The theme worth carrying forward

Nearly every serious defect this session was **a check that could not fail**, and each was only exposed
by running the real thing against real systems:

- Login proven by URL substring → the public portal passed; a run would have scraped a sign-in page as authenticated data (fixed, D120: two content-level facts).
- The parity lane rewrote its own expectations, and had already shipped 8 self-contradictory reference pairs (fixed, D132/D145: `maxDiffPixels: 0`, measured floor is 0).
- A catalog freshness test healed the artifact it policed.
- `descriptor-coverage` compared parsed objects while its byte-exact arm was wired to no script.
- A unit test recursively deleted the real `.auth-rebuild/` including the Duo credential.
- An assertion pinned one workflow name instead of deriving from the registry.

**And the best evidence the architecture earns its cost:** Kuali returned HTTP 200 and rendered
"Form saved" for a write that never persisted. The kernel read back, saw `absent`, parked as
`unknown`, and wrote zero ledger entries. A system that trusted that banner would have recorded an
HR transaction that never happened.

When adding a guard or test in 2h, the bar is: **prove it fails when it should**, with a negative
control executed against a violating fixture. That is the house style (`tests/unit/architecture/helpers/ratchet-arms.ts`).
