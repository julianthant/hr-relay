    A familiar setup. Your own keys.

    Connect only your own Duo account in your own browser.

    1. Install the clean extension

      For your own installation, unzip the clean package, then open chrome://extensions. Turn on Developer mode and choose Load unpacked. Keep the folder in place.

    2. Add your account

      Enter your primary Duo username and an optional sign-in link. Under Manage, add alternate usernames that use the same keys. Create a separate account for a separate key set.

    3. Authorize a new device

      Sign in, open Duo’s device management, and approve with an existing method. Select that Duo tab here, start capture, and add a security key or platform key in Duo.

    4. Finish in Duo

      Wait for Duo to confirm the device was added. Confirm that here, or test a login: an exact key request from Duo automatically activates the captured key.

    How the right account is chosen

    Duo’s requested key IDs are checked first. An exact visible primary or alternate username can narrow the match. When Duo sends no key IDs, a visible username and a matching discoverable key are required. Missing or conflicting identity leaves the request to your usual Duo method.

    Page layouts differ. Username detection supports labeled username fields and lines; it does not guess from unrelated text or read other websites.

    Use and privacy

    Use only your own Duo account. Never share your personal installation folder or credentials. Clean packages contain no personal accounts or keys.
